# 00_AI — CONTROL LAYER

This directory is the control layer for the PhD thesis + associated research projects.

It contains the rules, scope, priorities, evidence controls, decision log, literature/figure registers, and task queue used by the AI-assisted workflow.

## Source-of-truth principle

The AI must not treat a polished manuscript paragraph as stronger evidence than the underlying analysis or experiment. The intended evidence hierarchy is documented in `SOURCE_OF_TRUTH.md`.

## Active priorities

1. Mimotopes project review/remake and preparation of the corresponding thesis section.
2. Minimal pan-cancer analysis required to support thesis Parts I and II, plus initial thesis figures.
3. Complete and iteratively review the thesis until submission.
4. Resume publication finalization after thesis submission.

Publication 2 manuscript development is intentionally deferred, but the pan-cancer project is active because it supplies evidence for the thesis.

Start by reading:

1. `AI_MASTER_INSTRUCTIONS.md`

3. `PROJECT_MAP.md`
4. `THESIS_CHAPTER_MAP.md`
5. `SOURCE_OF_TRUTH.md`
