# AI WORKFLOW PROTOCOL

## Standard project session

1. Read `00_AI/AI_MASTER_INSTRUCTIONS.md`.
2. Read the relevant priority and project README.
3. State the current objective in one sentence.
4. Inspect existing evidence before proposing new work.
5. Separate known facts, derived results, interpretation, and open questions.
6. Propose the smallest useful next action.
7. Execute the action without modifying source-of-truth files unless explicitly authorized.
8. Validate the result.
9. Record important findings/decisions in the appropriate control file.
10. Keep generated working documents inside the project `AI_WORK` area.

## For code

**Read-only audit → plan → isolated change → test/QC → report → human review.**

## For figures

**Question → input → analysis → result → takeaway → destination.**

## For writing

**Scientific content check → structure → logic → evidence → clarity → style.**

## For literature

**Question → search → primary source → verify claim → record source → integrate.**
