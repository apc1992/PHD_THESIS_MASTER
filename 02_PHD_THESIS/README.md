# 02_PHD_THESIS

The thesis is a book-style dissertation organized into three scientific parts.

- `rules` — institutional rules; authoritative
- `templates` — institutional/template material
- `thesis_draft` — current thesis draft(s)
- `AI_WORK` — AI-assisted planning, review and chapter development

The three scientific parts are defined in `00_AI/THESIS_CHAPTER_MAP.md`.
