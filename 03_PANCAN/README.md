# 03_PANCAN

The pan-cancer project is active for thesis support but the full Publication 2 manuscript is deferred until after thesis submission.

## Working rule

First reconstruct the analytical state. Then define the minimum analysis required by explicit thesis questions. Do not expand the analysis simply because additional analyses are available.

## Directories

- `cohort` — sample inventory and cohort-level metadata/tracking
- `current_plan` — current scientific plan and minimal thesis analysis plan
- `analyses` — analysis code/outputs organized by purpose
- `figures` — existing and thesis candidate figures
- `tables` — existing and thesis candidate tables
- `data` — permissible project data/derived data used locally
- `thesis_outputs` — curated outputs specifically selected for the thesis
- `AI_WORK` — AI-assisted inventory, planning and execution notes
- `manuscript_future` — material reserved for the later full Publication 2 manuscript

## First deliverable

Populate `cohort/PANCAN_SAMPLE_ANALYSIS_MATRIX.xlsx` with one sample per row and one pipeline/analysis per column, then define each analysis in the workbook `Analysis_Register` sheet.
