# COHORT

This directory contains the sample-level inventory and cohort summaries needed to understand analytical coverage.

## Central workbook

`PANCAN_SAMPLE_ANALYSIS_MATRIX.xlsx`

- `Sample_Matrix`: one sample per row; analysis/pipeline statuses as columns
- `Analysis_Register`: defines what each analysis means, its input/output and thesis relevance
- `Cohort_Summary`: summarizes analysis coverage
- `Status_Definitions`: controlled vocabulary for status labels

The existing `samples_summary_analysis.xlsx` from the original project should be reviewed and incorporated here rather than silently discarded.
