# PAN-CANCER COHORT INVENTORY — START HERE

1. Open `PANCAN_SAMPLE_ANALYSIS_MATRIX.xlsx`.
2. Enter or paste one sample per row in `Sample_Matrix`.
3. Replace AN01–AN30 with the actual pipeline/analysis names used in the project.
4. Fill each sample × analysis cell using the controlled statuses.
5. Define every analysis in `Analysis_Register`.
6. Use `Cohort_Summary` to identify analytical gaps.
7. Do not define new analyses until the matrix and register are sufficiently complete to show what is already available.

The purpose of this workbook is planning and provenance, not replacing the underlying analysis logs or result files.
